# Changelog

## 1.0.0 - 2026-11-24

- Added a native **Ship All** button to the Warehouse screen.
- Added one-click processing for all fulfillable orders, including off-screen orders.
- Preserved insufficient-stock orders for later fulfillment.
- Removed packing animation and packing-time advancement from batch shipping.
- Added immediate order-list and inventory refresh.
- Used native delivery status transitions so online-shop revenue is recorded correctly.
- Added duplicate protection, transactional inventory rollback, and malformed-order handling.
- Published the original source code and documentation under the MIT License.
- Added third-party notices and a reproducible source-build workflow that does not redistribute game or BepInEx files.
